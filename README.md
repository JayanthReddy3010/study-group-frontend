# 🎓 Study Group Finder - Frontend

A modern AI-powered Study Group Finder web application built using **React + Vite** ⚡

It helps students connect, form study groups, chat in real-time, and improve learning efficiency 🚀

---

## 🌐 Live Demo

👉 https://study-group-frontend-3tvwhkvct-gjayanthreddy69-2878s-projects.vercel.app/

---

## ✨ Features

- 🔐 User Authentication (Login/Register)
- 🤖 AI-based Group Recommendations
- 💬 Real-time Chat (Socket.io)
- 👤 Profile Management
- 📊 Dashboard with analytics
- 📚 Study Group system
- 📅 Schedule tracking

---

## 🛠️ Tech Stack

- React.js ⚛️
- Vite ⚡
- Axios 🌐
- Socket.io Client 💬
- Tailwind CSS 🎨
- React Router 🚏
